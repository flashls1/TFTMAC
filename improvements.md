## 3. Four-Tier Decoupling Pipeline Architecture

1. **Tier 1 — Transport Decoupling (Deployed in current build):**
   - Ring expanded: $32\text{ KB} \rightarrow 256\text{ KB}$ (`hw.gltransport.asg.dataRingSize=262144`).
   - Write step: $16\text{ KB} \rightarrow 64\text{ KB}$ (`hw.gltransport.asg.writeStepSize=65536`).
   - Draw flush batch interval: $2000\text{ µs}$ (`hw.gltransport.drawFlushInterval=2000`).
2. **Tier 2 — Buffer Lifecycle Decoupling (Lever 2 - Next):**
   - Retain logical buffer views in ANGLE across consecutive frames.
   - Prevent aggressive deallocation on dynamic vertex/index uploads.
3. **Tier 3 — Shader / PSO Compilation Decoupling (Lever 3):**
   - Enable host pipeline cache (`VkPipelineCache`) and asynchronous background shader compiling to prevent Metal MSL compile freezes on host.
4. **Tier 4 — Presentation & Swapchain Decoupling (Lever 4):**
   - Decouple SurfaceFlinger presentation fences using mailbox pacing so engine main-thread stalls do not block the host display compositor.
